## ✨ Características Principales

* **🌊 Dirección Visual Editorial:** Paleta de colores oceánica profunda (`#061C2D`), arena cálida y acentos coral (`#FF334B`) con tipografía moderna.
* **⚡ 0 Dependencias Pesadas:** Construido íntegramente con HTML5 semántico, CSS3 moderno (Flexbox y CSS Grid) y JavaScript nativo. Carga instantánea y máxima optimización.
* **🏄 El Método en 4 Fases de Cody:** Módulo pedagógico con pestañas interactivas y esquemas visuales de la anatomía de la tabla de surf (*Sweet Spot*, *Nose* y *Tail*).
* **❤️ Galería con Likes Interactivos:** Tarjetas fotográficas con animación de corazón pulsante en rojo vivo y contador reactivo en tiempo real.
* **🛒 Carrito de Reserva de Equipamiento:** Selección dinámica de tablas y accesorios con etiquetas interactivas descartables `(×)`, botón de vaciado rápido y cálculo automático.
* **🎥 Hub de Videos Nativo:** Reproductor con selector de lecciones fluido y descripciones pedagógicas.
* **📱 100% Mobile-First:** Menú lateral desplegable con efecto *glassmorphism* (backdrop blur) y carruseles táctiles de deslizamiento natural.
* **🪄 Microinteracciones & UX:** Animaciones de entrada suave (*Scroll Reveal*) con `IntersectionObserver`, cabecera fija inteligente (*Sticky Header*) y botón flotante *Volver Arriba*.

## 🚀 Cómo Publicar en GitHub Pages en 3 Pasos

1. **Subir los archivos a tu repositorio:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Cody's Surf Guide web"
   git branch -M main
   git remote add origin https://github.com/<tu-usuario>/<nombre-repositorio>.git
   git push -u origin main
   ```

2. **Activar GitHub Pages:**
   * En tu repositorio de GitHub, dirígete a la pestaña **Settings** (Configuración).
   * En el menú izquierdo, selecciona **Pages**.
   * Bajo **Build and deployment > Source**, asegúrate de que esté seleccionado **Deploy from a branch**.
   * En **Branch**, selecciona la rama `main` y la carpeta `/ (root)`. Haz clic en **Save**.

3. **¡Listo!** En unos minutos, GitHub te dará el enlace público con tu sitio web funcionando online en todo el mundo.
